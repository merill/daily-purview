Encryption Azure Ad Configuration

25 November 2026Doc update+3 / −2 lines

In brief

The page now lists Commercial-to-Government/China, Government-to-Commercial, and China-to-Commercial access. The phrase stating access could be enabled without contacting Microsoft was removed.

What Purview admins need to know

Administrators should use the revised cloud-pairing list and contact guidance when reviewing encryption access configurations.
