Purview Adaptive Scopes

24 November 2026Doc update+22 / −3 lines

In brief

The page now explains rolling date filters, supported properties for users, groups, and SharePoint sites, ISO 8601 duration syntax, and query validation guidance.

What Purview admins need to know

Administrators can define adaptive-scope membership using dates relative to evaluation time and validate queries by converting durations to absolute UTC dates.

You can easily specify the attributes and properties listed in the table when you configure an adaptive scope by using the simple query builder. The advanced query builder supports additional attributes and properties, as described in the following section.

Use relative date filters

Use relative date filters in the advanced query builder to define scope membership by a rolling date range instead of a fixed date. For example, WhenMailboxCreated -ge 'P30D' selects mailboxes created on or after the date 30 days before evaluation. The date is recalculated each time the scope is evaluated.

Relative date filters support these properties:

Adaptive scope typeSupported date properties
Users and Microsoft 365 GroupsWhenCreated, WhenCreatedUTC, WhenMailboxCreated, WhenChanged, WhenChangedUTC, WhenSoftDeleted
SharePoint sitesCreated, RefinableDate00 through RefinableDate19

Specify a date-only ISO 8601 duration, such as P30D for 30 days, P2W for two weeks, P6M for six months, or P1Y for one year. You can combine years, months, and days, such as P1Y6M, but weeks must be used on their own.

For syntax, property descriptions, use cases, and validation guidance, see Use relative date filters in adaptive scopes.

How to configure an adaptive scope

Before you configure your adaptive scope, use the previous section to identify what type of scope to create and what attributes and values to use. You might need to work with other administrators to confirm this information.

  • Use PowerShell for the scope types Users and Microsoft 365 Groups
  • Use SharePoint search for the scope type SharePoint sites

Note

Adaptive scopes resolve relative date values such as P30D before evaluating a query. To test the query with Exchange PowerShell or SharePoint search, first replace each duration with an absolute UTC date. For an example, see Validate relative date filters.

To run a query by using PowerShell

  1. Connect to Exchange Online PowerShell by using an account with appropriate Exchange Online Administrator permissions.
