Some features used in this scenario are in preview.

This article uses the process you learned in Design a data loss prevention policy to show you how to create a Microsoft Purview data loss prevention (DLP) policy that helps prevent sharing sensitive information with unmanaged AI apps through network data security using an integrated SASE solution, such as Microsoft Entra Global Secure Access, firewall, such as Azure Firewall (preview), or non-Microsoft secure browser solution. Work through this scenario in your test environment to familiarize yourself with the policy creation UI.

Important

Before you begin, make sure the following prerequisites and assumptions are met:

  • You have an supported SASE or secure enterprise browser integration. For more information on which integrations are supported, see the Security Store in Microsoft Purview Data Loss Prevention.
  • If you're using Microsoft Entra Global Secure Access
    • The device must be Entra ID joined.Access, see Create a content policy to filter network content.
    • You must configure a Transport Layer Security inspection policy
    • You must configure a content policy in Microsoft Entra GSA Internet AccessIf you're using Azure Firewall (preview), see Configure network DLP with Azure Firewall and Microsoft Purview (preview).
  • If you are using a non-Microsoft SASE or secure enterprise browser provider
    • Ensure you've configured Purview pay-as-you-go billing. For more information, see Enable Microsoft Purview pay-as-you-go features for new customers.
    • Ensure you've completed the integration steps outlined in your provider's documentation.
