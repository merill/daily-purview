Edisc Search Teams Data

18 November 2026Feature updateAction required+34 / −8 lines

In brief

The documentation now specifies that `teamsMessages` purges permanently delete Teams messages, regardless of `purgeType`. Mailbox and Teams purges require separate requests, with Teams purged first; the API returns a `202 Accepted` response with a status URL.

What Purview admins need to know

Administrators using Graph must select the correct purge area, avoid combined values, and follow the required order to prevent irreversible or incomplete deletion.
