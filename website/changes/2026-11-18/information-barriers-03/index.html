Information Barriers

18 November 2026New feature+10 / −4 lines

In brief

The documentation adds that Agent Builder honors Information Barriers policies in its people picker, hiding users whom a user is restricted from communicating or collaborating with.

What Purview admins need to know

Administrators should expect Information Barriers restrictions to apply when users search for people in Agent Builder.

Before you define and apply IB policies, remove all existing Exchange address book policies in your organization. IB policies rely on address book policies, and existing ABPs aren't compatible with the ABPs that IB creates. To remove your existing address book policies, see Remove an address book policy in Exchange Online. When you enable IB policies and enable hierarchical address book, all users not included in an IB segment see the hierarchical address book in Exchange Online.

Information Barriers and Agent Builder experience

Agent Builder provides an easy way to build Declarative agent in Microsoft 365. It offers an immediate, interactive AI development experience that suits quick and straightforward projects.

Agent builder honors IB policies in the people picker experience. With IB support in Agent builder, when an IB user searches for other users in the people picker, they won’t see users they’re restricted from communicating and collaborating with per IB policy. This restriction prevents users from conflicting segments to share an agent with each other. Users can continue to access agents that was previously shared with them. However, any new sharing experience via people picker will be allowed only with the users who can collaborate with each other per IB policy.
