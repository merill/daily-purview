In brief

The article now states that the action requires an existing Microsoft Purview Message Encryption branding template, does not encrypt messages itself, and should be used in Exchange-only policies for internal senders. It also documents the external-recipient portal option.

What Purview admins need to know

Administrators configuring this action should verify the branding template, policy scope, and desired portal-access behavior.
