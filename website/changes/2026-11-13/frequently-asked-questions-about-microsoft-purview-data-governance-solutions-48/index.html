Frequently Asked Questions About Microsoft Purview Data Governance Solutions

13 November 2026Retirement+15 / −2 lines

In brief

The FAQ now states that Unified Catalog and classic Purview data governance capabilities are being retired and that new accounts can no longer be created.

What Purview admins need to know

Administrators should account for the account-creation restriction and the move to Microsoft Fabric when planning governance deployments.

Important

Microsoft Purview Unified Catalog and classic Microsoft Purview data governance capabilities (formerly Azure Purview) are being retired. Important

Microsoft Purview Unified Catalog and classic Microsoft Purview data governance capabilities (formerly Azure Purview) are being retired. Microsoft is consolidating its data governance capabilities in Microsoft Fabric. You can no longer create new accounts, and existing capabilities will remain in maintenance mode through November 12, 2027. For retirement timelines, transition guidance, and recommended next steps, see the Microsoft Purview data governance retirement announcement.

Overview

Many organizations lack a holistic understanding of their data. It's challenging to understand what data exists, where data is located, and how to find and access relevant data. Data lacks context such as lineage, classification, and comprehensive metadata, making it difficult for business users to search for the right data and use that data appropriately. As a result, only a small fraction of collected data is used to inform business decisions. Finally, identifying data security issues and protecting sensitive data is inconsistent. It requires ongoing time and effort, especially while maintaining data agility.
