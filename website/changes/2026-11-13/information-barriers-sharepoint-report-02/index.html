Information Barriers Sharepoint Report

13 November 2026Feature update+3 / −3 lines

In brief

The documentation now states that users with the SharePoint Embedded Administrator role can run the report and update segments for user-owned containers.

What Purview admins need to know

Administrators should consider this role when assigning report and segment-management responsibilities.
