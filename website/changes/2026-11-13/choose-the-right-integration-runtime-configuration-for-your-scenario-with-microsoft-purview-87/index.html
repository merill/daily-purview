Choose the right integration runtime configuration for your scenario with Microsoft Purview

13 November 2026Retirement+9 / −3 lines

In brief

The documentation now states that Unified Catalog and classic Purview data governance capabilities are being retired and consolidated in Microsoft Fabric. New accounts can no longer be created.

What Purview admins need to know

Administrators should account for the inability to create new Purview accounts when planning data governance deployments.

Choose the right integration runtime configuration for your scenario with Microsoft Purview | Microsoft Learn

Important

Microsoft Purview Unified Catalog and classic Microsoft Purview data governance capabilities (formerly Azure Purview) are being retired. Microsoft is consolidating its data governance capabilities in Microsoft Fabric. You can no longer create new accounts, and existing capabilities will remain in maintenance mode through November 12, 2027. For retirement timelines, transition guidance, and recommended next steps, see the Microsoft Purview data governance retirement announcement.

The integration runtime (IR) is the compute infrastructure that Microsoft Purview uses to power data scan across different network environments. This article introduces the different types of integration runtime available in Microsoft Purview, and provides guidance on how to choose the right integration runtime configuration for your scenario.
