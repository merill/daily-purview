Policies and rules

Create Retention Policies

5 November 2026Feature updateAction required+8 / −5 lines

In brief

Beginning January 15, 2027, policies using “Teams chats and Copilot interactions” will apply only to Teams content. They will no longer retain or delete Microsoft 365 Copilot interactions, including previously retained interactions.

What Purview admins need to know

If Copilot retention coverage is required, create a separate retention policy using the “Microsoft Copilot Experiences” location. Teams retention behavior is unchanged.
