Microsoft Purview: Adaptive scopes add lifecycle status evaluation controls for recipients and site owners

14 November 2026MC1450128 on mc.merill.net ↗Message

In brief

Microsoft Purview is updating adaptive scopes to evaluate only active recipients and site owners by default, with options to include inactive or soft-deleted ones. This includes ISO 8601 duration support in queries. Rollout starts December 2026 (preview) and April 2027 (general availability). No immediate action required.

Message Center announcement

Updated November 13, 2026: We have updated the timeline. Thank you for your patience. 

What and why

Microsoft Purview is introducing lifecycle status evaluation controls for adaptive scopes. This update gives administrators explicit control over whether active, inactive, and soft-deleted recipients and site owners are included in adaptive scope membership.

With this change, newly created adaptive scopes will evaluate only active recipients and site owners by default. Administrators can configure adaptive scopes to include inactive and/or soft-deleted recipients and site owners when needed.

This update also adds support for ISO 8601 duration values for selected date attributes in the adaptive scope advanced query builder.

This message is associated with Microsoft 365 Roadmap ID 568785.

Rollout schedule

  • Public Preview: Beginning in December 2026 (previously mid-September) and expected to complete in December 2026 (previously early October)
  • General Availability (Worldwide): Beginning in April 2027 (previously mid-October 2026) and expected to complete in April 2027 (previously mid-November 2026)

Impact on your organization

Who is affected

  • Microsoft Purview administrators who create or manage adaptive scopes.
  • Organizations that use adaptive scopes for Microsoft Purview policy targeting.

Platforms and services

  • Microsoft Purview
  • Adaptive Scopes

What will happen

Existing adaptive scopes will continue to function as they do today and will not be automatically modified as part of this rollout.

For newly created adaptive scopes:

  • Active recipients and site owners will be evaluated by default.
  • Inactive and soft-deleted recipients or site owners will not be included unless explicitly configured by an administrator.

Administrators will also have the option to update existing adaptive scopes to use explicit lifecycle status evaluation criteria for recipients and site owners.

Additionally, adaptive scopes will support ISO 8601 duration values for certain date-based attributes in the advanced query builder.

Action required and recommendations

No action is required before rollout.

We recommend that administrators:

  • Review current adaptive scope configurations and governance requirements.
  • Determine whether inactive or soft-deleted recipients and site owners should be included in future adaptive scope definitions.
  • Update adaptive scope creation processes and documentation, if applicable, to account for the new lifecycle status settings.
