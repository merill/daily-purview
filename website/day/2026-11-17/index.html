Day in brief

Adaptive protection preview targets 120-day labels for high-risk-user deletions

Data Lifecycle Management’s Adaptive protection integration is the standout capability change: the public preview automatically applies retention labels to content deleted by elevated-risk users for 120 days, with general availability listed for early 2027. Other meaningful updates cover 2027 PST Import planning, a Teams Information Barriers procedure, Clipchamp label inheritance, and more precise auto-label reporting guidance.

  • Purview · General
    Adaptive protection integrates with Data Lifecycle Management

    The public-preview integration automatically applies retention labels to content deleted by elevated-risk users for 120 days. Microsoft lists general availability for early 2027 and describes the setup as requiring minimal administrator configuration.

  • Purview · General
    Azure PST Import is scheduled to begin in April 2027

    Admins will import PST files from Azure Blob Storage into Exchange Online mailboxes through PowerShell, with readiness analysis and import batching. The rollout requires specified Azure permissions and mailbox prerequisites, and imported data remains subject to existing retention and audit policies.

  • Communication Compliance · General
    Information Barriers guidance documents Explicit-mode Teams conversion

    The updated guidance explains how to change a Teams-connected Microsoft 365 group from Implicit to Explicit mode with PowerShell. It documents segment-based access and membership, up to 24 hours for segment stamping, and the restriction that site owners and SharePoint admins cannot manage segments on Explicit-mode Teams-connected sites. Owner moderated and Open modes cannot be transitioned.

  • Information Protection · Labels and classification
    Clipchamp labeling is tied to EnableSensitivityLabelForVideoFiles

    The revised sensitivity-label guidance says `EnableSensitivityLabelForVideoFiles` controls labeling for Clipchamp projects and whether exported MP4 files inherit the project’s label. Administrators should use the tenant’s current setting value when assessing the effect.

  • Information Protection · Labels and classification
    Auto Label Insights separates progress from recorded activity

    The updated guidance distinguishes periodically refreshed labeling progress from recorded labeling activity over the last 30 days. Activity counts labeling operations rather than distinct files, and the documentation points admins to the newer full review experience for daily trends.

Labels and classification

Auto Label Insights Tab

Doc update

The documentation now distinguishes periodically refreshed labeling progress from recorded labeling activity over the last 30 days. It clarifies that activity counts operations rather than distinct files, updates metric definitions, and points to the newer full review experience for daily trends.

Apply Sensitivity Label Automatically

Doc update

The article now explains that a file can contribute multiple recorded labeling operations, that activity excludes some accesses, scans, evaluations, and retries, and that deleting a file does not remove historical activity. It also links to metric guidance and troubleshooting for count discrepancies or incomplete reports.

Sensitivity Labels Sharepoint Onedrive Files

Feature update

The `EnableSensitivityLabelForVideoFiles` setting now controls Clipchamp project labeling and whether exported MP4 files inherit the project’s label.

Sensitivity Labels Versions

Doc update

The guidance now explains that opening Excel, PowerPoint, or Word files beside a Copilot conversation in the Microsoft Copilot app uses the web versions of those apps, so the Web column applies.
