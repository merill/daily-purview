23 November 2026

Microsoft Purview | Data Lifecycle Management - Archive SharePoint files under retention

Message CenterMC1325441 on mc.merill.net ↗Stay informed
General

Microsoft Purview Data Lifecycle Management will add an Archive option to retention policies, allowing admins to move inactive SharePoint files to Microsoft 365 Archive for cost savings while maintaining compliance and discoverability. Archived content is excluded from Copilot indexing. Rollout begins September 2026; admin configuration is required.

General

Microsoft Purview introduces a priority cleanup workflow allowing admins to hard delete specific OneDrive and SharePoint content, overriding retention policies with eDiscovery admin approval. Rolling out mid-August 2026 (preview) and early December 2026 (general availability), this feature requires explicit admin setup and supports compliance oversight.

Microsoft Purview: Archive SharePoint files under retention policies
